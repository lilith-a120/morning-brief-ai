# Morning Brief AI

매일 아침 여러 뉴스 사이트를 돌아다니지 않고, 중요한 소식을 한 번에 확인할 수 있다면 어떨까?

이런 생각에서 시작한 개인 프로젝트입니다.

Morning Brief AI는 RAG(Retrieval-Augmented Generation) 기술을 활용한 뉴스 브리핑 프로그램입니다. Google News RSS에서 뉴스를 수집하고, 사용자가 질문하면 관련 기사를 검색한 뒤 Gemini AI가 검색 결과를 바탕으로 답변을 생성합니다.

현재는 대학 과제를 위한 초기 버전으로, 뉴스 수집과 검색, AI 요약 기능을 중심으로 구현했습니다.

## 주요 기능

- Google News RSS를 통한 뉴스 수집
- SQLite를 활용한 기사 저장 및 관리
- 문자 유사도 검색 및 선택적 의미 기반 검색
- Gemini API를 활용한 뉴스 요약과 질의응답
- 검색된 기사의 출처 표시
- 웹사이트에서 직접 브리핑 조회

## 개발 환경

Python, Streamlit, SQLite, Sentence Transformers, Gemini API

## 향후 개발 계획

현재는 중요한 RAG 기능을 구현한 단계입니다. 앞으로 자동 이메일 브리핑, 개인 관심 분야에 따른 뉴스 선정, 주가 및 환율 조회 기능 등을 추가할 계획입니다.

최종적으로는 사용자가 원하는 시간에 하루의 주요 소식을 자동으로 전달받고, 궁금한 사건은 직접 질문할 수 있는 개인 맞춤형 뉴스 서비스로 발전시키는 것이 목표입니다.
