# Morning Brief AI — 실행형 RAG 과제 샘플

**실제 구현 포함:** Google News RSS 기사 수집, SQLite 저장, 문자 n-gram 유사도 검색, 외부 LLM 기반 근거 답변(키 필요), 출처 링크, 수동 브리핑, 예약 이메일 ON/OFF와 즉시 발송 테스트.

**범위 제한:** 금융시장 시세는 아직 미구현. 기본 검색은 가벼운 n-gram 방식이고, 의미 기반 임베딩을 활성화하려면 추가 라이브러리 설치가 필요. 자동 발송은 컴퓨터/서버에서 `scheduler.py`가 계속 실행될 때만 동작. Google News RSS는 기사 **전체 본문이 아닌 제목·요약**만 제공할 수 있음.

## 1. 실행 (Mac / PyCharm 터미널)

```bash
cd morning_brief_ai
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python -m streamlit run app.py
```

Windows: `.venv\Scripts\activate` 를 사용하세요.

브라우저에서 로컬 앱이 열리면 `실제 뉴스 RSS 수집` 버튼을 클릭합니다. 인터넷이 안 되면 `연습용 기사 불러오기`로 시연할 수 있습니다. **연습용 데이터는 실제 뉴스가 아닙니다.**

## 2. AI 답변 사용

`.env` 파일의 `OPENAI_API_KEY=` 뒤에 본인의 API 키를 입력하고 Streamlit을 재시작하세요. 실제 API 호출 비용이 발생할 수 있습니다. API 키 없이도 기사 수집과 검색은 작동하지만 생성형 AI 답변 대신 **검색 근거 미리보기**가 표시됩니다. ChatGPT 구독과 API 과금은 별개입니다.

선택: 의미 기반 임베딩 검색을 시험하려면 `python -m pip install -r requirements-semantic.txt`를 실행한 뒤, 사이드바 `의미 기반 임베딩 검색`을 켜세요. 최초 모델 다운로드 시 인터넷 접속이 필요합니다. 기본 검색은 문자 2~3그램 유사도 기반으로 별도 ML 패키지가 필요하지 않습니다.

## 3. 이메일 알림 테스트

이메일 기능을 사용하려면 `.env`에서 `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`를 설정하세요. Gmail의 경우 계정 보안 설정에 따라 앱 비밀번호가 필요할 수 있습니다. **실제 비밀번호나 API 키를 제출하지 마세요.**

앱 사이드바에서 수신 이메일, 발송 시각(한국시간), 자동 발송 ON/OFF, 관심 분야를 선택하고 **설정 저장**을 누릅니다. `알림 테스트` 탭에서 즉시 발송을 시험할 수 있습니다.

자동 발송은 **두 번째 터미널**에서 다음 명령을 실행한 채 두세요.

```bash
source .venv/bin/activate
python scheduler.py
```

예약 프로그램이 30초 간격으로 시각을 확인하며, 하루 1회 발송합니다. 꺼두면 메일을 보내지 않습니다. 컴퓨터가 잠들거나 종료되면 자동 발송이 멈춥니다. 실제 24시간 운영에는 서버 및 운영 설정이 추가로 필요합니다.

## 4. 과제 시연 순서

1. 앱 실행 → 연습용 기사로 기본 기능 확인.
2. `실제 뉴스 RSS 수집` 클릭 → 실제 기사와 출처 확인 (온라인 환경).
3. `뉴스에 질문하기` → 관련 기사 검색 결과 확인.
4. (API 키 있으면) 실제 AI 답변 및 근거 번호 표시.
5. 설정에서 자동 이메일 ON/OFF 저장 → 테스트 이메일 발송 (SMTP 정보 필요).
6. 예약 발송 시연은 별도 `scheduler.py` 실행 및 예약 시각 지정.

## 5. 주의점

- RSS 검색 결과가 지연되거나 중복될 수 있고, 출처의 정확성이 자동 보장되지는 않습니다.
- 실시간 금융 시세 기능은 이 샘플에 포함되지 않습니다.
- OpenAI API 장애 또는 키 누락 시에는 AI 생성 결과 대신 검색 근거를 출력합니다.
- 전체 기사 원문 수집/재배포 대신 RSS의 제공 범위 내 메타데이터와 원문 링크를 이용합니다.
- 이 프로젝트를 외부에 공개하기 전에는 인증, 개인정보 보호, 이메일 남용 방지 및 뉴스 서비스 이용약관 검토가 필요합니다.
